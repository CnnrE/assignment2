Question 5: What is the difference between git log and git status?

The git log command displays the history of commits in a repository.

The git status command shows the current state of the working directory.

Question 8: Explain inheritance, polymorphism, and encapsulation.

I. Inheritance:
Inheritance allows a class to inherit properties and methods from another class. This helps reuse code and avoid duplication.

II. Polymorphism:
Polymorphism allows objects of different classes to be treated through a common interface while performing different behaviors.
For example, different classes can implement the same method in different ways.

III. Encapsulation:
Encapsulation means keeping data and the methods that work with it together in a class while restricting direct access to certain data.
This helps protect data and control how it is modified.

Question 9: What is the main difference between the Dictator and Lieutenants workflow and the Integration Manager workflow?

In the Integration Manager workflow, one manager handles merging everyone's changes. In the Dictator and Lieutenants workflow,
lieutenants merge changes from smaller groups of developers before passing them to the dictator, who handles the final merge.

Question 10: How would a team of 100 developers benefit from the Dictator and Lieutenants workflow instead of the Centralized workflow?

The Dictator and Lieutenants workflow would make managing 100 developers easier by dividing the work into smaller groups.
Lieutenants can handle changes and conflicts within their groups, reducing the workload on the dictator.
This makes development more organized than having everyone work directly with one shared repository.
